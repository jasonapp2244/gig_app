# Gig Mobile App - Laravel Backend API

A robust Laravel-based backend API for a gig economy mobile application that connects freelancers with clients for various services and tasks.

## 🚀 Features

### Core Functionality
- **User Management**: Multi-role system (User, Employer, Freelancer)
- **Task Management**: Create, assign, and track gig tasks
- **Payment Processing**: Secure payment handling with multiple payment methods
- **Real-time Notifications**: Firebase Cloud Messaging integration
- **Review System**: Rating and review mechanism for completed tasks
- **Category Management**: Organized service categories and subcategories

### Key Features
- **Authentication & Authorization**: Sanctum authentication with role-based access
- **Task Bidding System**: Freelancers can bid on available tasks
- **Reminder System**: Automated reminders for task deadlines
- **Media Management**: Image upload and management for task portfolios
- **Email Notifications**: Welcome emails, password resets

## 🛠️ Tech Stack

- **Backend Framework**: Laravel 12.0.x
- **Database**: MySQL
- **Authentication**: Laravel Sanctum
- **Queue System**: Laravel Queues for background jobs
- **Caching**: Redis (optional)
- **File Storage**: Local & Cloud storage support
- **API**: RESTful API with JSON responses
- **Notifications**: Firebase Cloud Messaging (FCM)
- **Email**: Laravel Mail with Blade templates

## 🚦 Getting Started

### Prerequisites
- PHP 8.2 or higher
- Composer
- MySQL 8.0+
- Laravel CLI
